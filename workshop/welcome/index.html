From OSM Data to a Shareable Map URL

This workshop guides you through turning OpenStreetMap data into a working web map you can share at your next community meetup — using only open tools and infrastructure you control.

What You'll Build

A standalone bike map of the Capital City State Trail in Madison, WI — rendered with MapLibre GL JS, data from OpenStreetMap, basemap tiles from the OSM US Tileservice, and terrain hillshade from Mapterhorn. Hosted for free on GitHub Pages. No API keys. No proprietary platform. No server required.

Workshop Steps

  • Before You Arrive — Fork the repo and install the tools you need before the session starts
  • Step 1 — Verify Setup — Start your local server and confirm everything is working
  • Step 2 — Extract Trail Data — Run an Overpass Ultra query to export the trail as GeoJSON
  • Step 3 — Render the Map — Add the trail layer to the MapLibre map in index.html
  • Step 4 — Publish to GitHub Pages — Push to GitHub and share your map URL
  • Step 5 — Add Terrain — Download hillshade tiles and add them via Maputnik
